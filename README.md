# Billar Azteca Marcador

Aplicación Android táctil para llevar el marcador de billar en Billar Azteca Club.

## Versiones

- `v3-stable`: versión funcional estable anterior.
- `main`: versión v4 con rediseño visual basado en el prototipo, logo real de Billar Azteca, cronómetro circular, jugador activo resaltado y botón Deshacer.

## Funciones

- Dos jugadores con nombres editables
- Distancia configurable
- Cronómetro configurable
- Reinicio automático del reloj al sumar +1
- Fin de turno cambia de jugador y reinicia el reloj
- Corrección -1
- Promedio automático
- Serie mayor
- Entrada actual
- Pausa / reanudar
- Reinicio manual del reloj
- Deshacer
- Nuevo partido
- Interfaz horizontal para pantalla táctil


## v5

- Logo real integrado directamente como recurso Android en el repositorio.
- Logo visible de 48 dp en el encabezado.
- Mejor alineación vertical y separación con el título.
- La lógica del marcador y cronómetro se mantiene sin cambios.
